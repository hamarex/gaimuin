# 証券外務員一種 学習アプリ

個人用の学習アプリです。証券外務員一種（日本証券業協会の資格試験）の教材を、1回30分程度ずつ進められるように区切っています。金融の前提知識がなくても読めるように、解説は平易にしています。

## 開き方

1. `app/index.html` をブラウザ（Chrome、Safari、Edge など）でダブルクリックして開きます。
2. インターネット接続は不要です。外部ライブラリや外部サイトは使っていません。
3. Node.js は、教材を直すとき（後述「教材の更新」）にだけ必要です。アプリを使うだけなら不要です。

## 使い方

### 基本の流れ

- ホームで「続きから」を押すと、前回の位置から再開できます。
- 1レッスンは小項目ごとの「ページ」に分かれています。1画面に1ページだけ表示され、「次へ」「前へ」で小分けに進みます。画面上部に「第N章 レッスン名 ・ ページ 3/12」と進捗バーが出ます。
- そのページに対応する○×問題があると、「次へ」で「確認クイズ」に進みます。クイズは1問ごとに採点され、すぐに解説が出ます（本文は「本文を読み返す」で見られます）。終わったら「次へ」で次のページです。問題のないページは直接次へ進みます。
- 「前へ」で戻ると本文が表示されます。回答済みのクイズは結果が表示され、「もう一度挑戦」もできます。
- レッスンの最後のページを終えるとレッスン完了になり、次のレッスンへ進みます（章の最後は章末テストの案内）。
- 「次へ」で6ページ進むごと（クイズの回答は数えません）に「ここまで読みました」の画面が出ます。「続ける」か「今日はここまで」（位置を保存してホームへ）を選べます。
- 位置はページ単位で保存され、再読み込みや「続きから」で同じページから再開できます。

### 章末テスト

- 章のレッスンをすべて終えると、五肢選択の章末テストに進めます。
- 正答率が合格基準（初期値 70%）以上なら合格で、次の章が開きます。不合格でも何度でも受けられます。
- 合格基準は「設定」で 10〜100% の範囲に変えられます。

### 総仕上げ（模擬試験）

- 全章の章末テストに合格すると開きます（設定の「全章を開放」でも開けます）。
- 本番形式です。○×70問（各2点）＋五肢選択30問（各10点）の 440点満点で、308点以上が合格です。未回答は0点です。
- 画面の時間は経過時間の表示です。制限時間は未確認のため設定していません。最新の受験案内で確認してください。

### 復習

- 間違えた問題が「復習」メニューに溜まります。正解すると一覧から外れます。
- 学習の流れの中には、間違えた問題は出しません。復習は別メニューです。

### 誤り報告（「これ間違いでは?」）

- レッスン、クイズの解説、総仕上げの結果には「これ間違いでは?」ボタンがあります。どこが違うと思ったかをメモとして残せます。
- 一覧はホームの「誤り報告」から見られます。「誤り報告を書き出す」で JSON ファイルに保存できます。設定の「進捗JSONを書き出す」にも含まれます。
- 書き出したファイルを Claude に渡せば、教材の修正に使えます。

## 進捗の保存

- 進捗はブラウザの localStorage（キー名 `gaimuin.progress.v1`）に自動保存されます。回答したとき、ページを移動したとき、レッスンを終えたときに保存されます。
- 保存先はブラウザごと、さらに開いたファイルの場所ごとに分かれます。`app` フォルダを移動したり、別のブラウザで開いたりすると、進捗が消えたように見えます。
- バックアップは「設定」→「進捗JSONを書き出す」で保存します。戻すときは「設定」→「読み込む」で選びます。読み込みに失敗した場合は、現在の進捗は変わりません。
- 「設定」→「すべて消去」で進捗を消せます（確認ダイアログが出ます）。
- 保存領域が使えない場合は、画面上部に警告が出ます。

## 教材の更新

教材の元データは `chapters/` の Markdown です。直したら、次のコマンドでアプリ用のデータを作り直します。

```
node tools/build.mjs
```

- `app/data.js` が再生成されます。エラーが出たときは何も書き換えずに終了します。
- ○×問題には、所属するレッスンの見出しを指定するタグ `<!-- sec: 見出し名 -->` が必要です。タグがない問題は警告「secなしQ」として数えられます。
- テストは次のコマンドで実行します。

```
node --test
```

## ディレクトリ構成

```
chapters/          教材の元データ（章ごとの Markdown。NN_*.md と NNb_choice.md）
tools/             Markdown を app/data.js に変換するスクリプト（build.mjs、parse.mjs）
app/               アプリ本体（index.html を開く。logic.js、data.js）
tests/             テスト（node --test で実行）
docs/factcheck/    ファクトチェック結果（ch01〜ch10）。修正一覧は summary.md
docs/superpowers/  設計書（specs）と実装計画（plans）
```

## 注意事項（限界）

- 教材は一次情報（法令、JPX、日本証券業協会、金融庁など）で確認しました。ただし、誤りがないことは保証できません。
- 確認の一部は、一次資料の本文を直接取得できていません。その箇所は「既知の制度として矛盾がない」という確認にとどまります（ファクトチェックの凡例で「正※」）。
- 本番の試験問題は非公開です。この教材の問題は「本番形式」の模擬問題で、本番と同じ問題ではありません。
- 2027年に変わる制度（呼値の決め方、国債先物の最終取引日、NISA の対象、税金の内訳など）は、本文に注記があります。
- 試験の前に、日本証券業協会の最新の受験案内で試験範囲と形式を必ず確認してください。
- ファクトチェックで直した内容と保留した箇所は `docs/factcheck/summary.md` にまとめています。
