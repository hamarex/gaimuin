### 5. 五肢選択問題と解説

- 問1. 【組合せ型】先物取引の仕組みに関する次の記述のうち、正しいものの組合せとして正しいものはどれか。
  - イ. 先渡し取引は、取引所において標準化された条件で取引され、清算機関が決済を保証する。
  - ロ. 日経225先物の最終取引日はSQ日の前営業日であり、SQ値はSQ日における指数構成銘柄の始値に基づいて算出される。
  - ハ. 長期国債先物取引の受渡適格銘柄は残存7年以上11年未満の10年利付国債であり、どの銘柄を受け渡すかは売り方が選択する。
  - ニ. 長期国債先物取引の取引単位は額面1億円であり、最終取引日は受渡決済期日の3営業日前である。
  - 選択肢：1. イ・ロ　2. イ・ハ　3. ロ・ハ　4. ロ・ニ　5. ハ・ニ
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**3**
    - イ：× 主語の入れ替え。標準化・清算機関の保証は**先物（フューチャーズ）取引**の特徴。先渡しは**店頭（相対）**で条件自由、相手方の**信用リスク**あり
    - ロ：○ 最終取引日＝**SQ日（第2金曜日）の前営業日**。SQ値は終値ではなく**始値**ベース
    - ハ：○ 受渡銘柄の選択権は**売り方**。売り方に最も有利な銘柄が**最割安銘柄（CTD）**
    - ニ：× 取引単位（額面1億円）は正しいが、最終取引日は受渡決済期日（各限月20日）の**5営業日前**（数値ずらし）
    - 絞り込みのコツ：イは「取引所・清算機関＝先物」の定番入れ替えで即×→1・2が消える。ニの「3営業日前」を×と判断できれば、残りは3のみ

- 問2. 【組合せ型】日経平均株価が38,300円のときのオプションに関する次の記述のうち、正しいものの組合せとして正しいものはどれか。
  - イ. 権利行使価格38,000円のプット・オプションは、イン・ザ・マネーである。
  - ロ. 権利行使価格38,000円のコール・オプションのプレミアムが520円であれば、その時間価値は300円である。
  - ハ. アウト・オブ・ザ・マネーのオプションのプレミアムは、すべて時間価値からなる。
  - ニ. デルタが0.6のコール・オプションは、原資産価格が150円上昇すると、プレミアムがおよそ90円上昇する。
  - 選択肢：1. イ・ロ　2. イ・ハ　3. ロ・ハ　4. ロ・ニ　5. ハ・ニ
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**5**
    - イ：× プットは**原資産＜行使価格**でITM。38,300＞38,000なので行使しても損＝**OTM**（コールならITM）
    - ロ：× 300円は**本源的価値**（38,300−38,000）。時間価値＝520−300＝**220円**（本源的価値と時間価値のすり替え）
    - ハ：○ OTM・ATMは本源的価値ゼロ→プレミアムは**全部が時間価値**
    - ニ：○ プレミアム変化≒デルタ×原資産の変化＝0.6×150＝**90円**
    - 絞り込みのコツ：イは「コールとプットのITM条件の逆転」で即×→1・2が消える。ロは引き算を一度するだけで×→3・4が消え、5が残る

- 問3. 【組合せ型】オプション戦略・スワップ取引に関する次の記述のうち、正しいものの組合せとして正しいものはどれか。
  - イ. プロテクティブ・プットは、現物の保有とプットの買いを組み合わせた戦略であり、その損益の形はコールの買いと同様になる。
  - ロ. 通貨スワップでは、原則として取引開始時と満期時に元本の交換が行われる。
  - ハ. ブル・プット・スプレッドは、低い権利行使価格のプットを売り、高い権利行使価格のプットを買う戦略である。
  - ニ. CDSのプロテクションの売り手は、定期的に保証料を支払う代わりに、参照組織にクレジット・イベントが発生した場合に損失の補償を受ける。
  - 選択肢：1. イ・ロ　2. イ・ハ　3. ロ・ハ　4. ロ・ニ　5. ハ・ニ
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**1**
    - イ：○ 値下がりはプットで保険、値上がり益は享受＝損失限定・利益無限大で**コールの買い**と同じ形
    - ロ：○ **異なる通貨**の金利と**元本**を交換。元本を交換しないのは**金利スワップ**
    - ハ：× 売り買いが逆。強気（ブル）は**低い行使価格を買い、高い行使価格を売る**（コール・プット共通）。記述はベア・プット・スプレッド
    - ニ：× 保証料を払って補償を受けるのは**プロテクションの買い手**。売り手は保証料を受け取り、補償義務を負う（主語の入れ替え）
    - 絞り込みのコツ：ロ（通貨スワップ＝元本交換あり）は確実に○→ロを含む1・3・4に絞る。ニは主語入れ替えで×→4が消える。ハの「ブル＝低い方を買う」で×→3が消え1

- 問4. 【正しいものはどれか】先物取引に関する次の記述のうち、正しいものはどれか。
  - 1. 将来受け取る資金で株式を購入する予定の投資家が、それまでの値上がりに備えて株価指数先物を売り建てることを、売りヘッジという。
  - 2. 株価指数先物の価格が理論価格より割安な場合には、現物を売り、先物を買う裁定取引が考えられる。
  - 3. 短期金利が配当利回りを上回っている場合、株価指数先物の理論価格は現物価格を下回る。
  - 4. カレンダー・スプレッド取引とは、日経225先物とTOPIX先物のように、異なる商品の先物を一方で買い、他方で売る取引である。
  - 5. 先物取引の値洗いにより生じた現金不足額は、代用有価証券を差し入れることで解消できる。
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**2**
    - 1：× 購入予定者が値上がりに備えるのは**先物の買い**＝**買いヘッジ**。売りヘッジは保有者が値下がりに備えるもの
    - 2：○ 割安な先物を**買い**、割高な現物を**売る**（**売り裁定**）。満期にベーシスがゼロに収束して利益確定
    - 3：× 理論価格＝現物×｛1＋（金利−配当利回り）×日数/365｝。金利＞配当利回りなら先物は現物を**上回る**
    - 4：× 記述は**商品間スプレッド**。カレンダー・スプレッドは**同じ商品の異なる限月**を売買する取引
    - 5：× 証拠金自体は代用有価証券でも差し入れ可能だが、値洗い損などの**現金不足額は現金**で差し入れる（原則と例外の逆転）
    - 絞り込みのコツ：「割高を売り、割安を買う」を当てはめれば2が即○。念のため1（ヘッジの向き）と3（キャリーコストの符号）を×と確認

- 問5. 【誤っているものはどれか】オプション取引およびデリバティブの規制に関する次の記述のうち、誤っているものはどれか。
  - 1. 他の条件が同じであれば、残存期間が長いほど、コール・プットともプレミアムは高くなる。
  - 2. 配当が増加すると、コールのプレミアムは下落し、プットのプレミアムは上昇する。
  - 3. オプションの買いのポジションはガンマがプラスとなり、売りのポジションはガンマがマイナスとなる。
  - 4. 取引所で取引される株価指数先物取引・オプション取引は、個人顧客に対する不招請勧誘の禁止の対象である。
  - 5. 個人顧客を相手方とする店頭FXの証拠金は想定元本の4%以上とされており、レバレッジは最大25倍となる。
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**4**
    - 1：○ 満期までの時間が長いほど有利になる可能性が大きい→**両方とも上昇**
    - 2：○ 配当が出ると原資産価格が下がる方向→コール**下落**、プット**上昇**
    - 3：○ 買いはガンマ・ベガがプラス、売りはマイナス
    - 4：× 不招請勧誘の禁止の対象は**個人顧客との店頭デリバティブ取引**。取引所の先物・オプション（市場デリバティブ）は**対象外**（勧誘受諾意思の確認義務・再勧誘の禁止は対象）
    - 5：○ 4%以上＝1÷0.04＝**25倍**
    - 絞り込みのコツ：規制系の記述（4・5）から先に確認。「不招請勧誘＝店頭」を覚えていれば4が即×

- 問6. 【計算型】日経平均株価（現物）が36,500円、短期金利が年1.2%、配当利回りが年0.4%、満期までの残存日数が50日のとき、日経225先物の理論価格として正しいものはどれか（1年は365日とする）。
  - 1. 36,460円
  - 2. 36,540円
  - 3. 36,560円
  - 4. 36,580円
  - 5. 36,792円
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**2**
    - 公式：**理論価格 ＝ 現物 ×｛1 ＋（金利 − 配当利回り）× 残存日数/365｝**
    - 途中式：金利−配当利回り＝1.2%−0.4%＝0.8%
    - キャリーコスト＝36,500×0.008×50/365
      - 36,500÷365＝100 を先に作ると楽：100×50×0.008＝**40円**
    - 理論価格＝36,500＋40＝**36,540円**
    - 1（36,460円）：金利と配当の符号を逆にした誤り（36,500−40）
    - 3（36,560円）：配当を引き忘れ（100×50×0.012＝60）
    - 4（36,580円）：配当を足してしまった誤り（1.2%＋0.4%＝1.6%→80）
    - 5（36,792円）：残存日数/365を掛け忘れ（36,500×1.008）
    - 検算：金利＞配当なので先物＞現物（36,500超）。1は除外でき、方向感も一致

- 問7. 【計算型】時価12億円の国内株式ポートフォリオ（TOPIXと同じ値動きをするものとする）を保有する投資家が、値下がりに備えてTOPIX先物（先物価格2,400ポイント）でヘッジを行った。その後、TOPIX先物が2,280ポイントに下落した時点で反対売買した。ヘッジに必要な枚数・売買の方向と、先物取引の損益の組合せとして正しいものはどれか（手数料等は考慮しない）。
  - 1. 50枚の買い／6,000万円の利益
  - 2. 500枚の売り／6億円の利益
  - 3. 5枚の売り／600万円の利益
  - 4. 50枚の売り／6,000万円の利益
  - 5. 50枚の売り／6,000万円の損失
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**4**

    - 1枚の想定元本＝2,400×**10,000円**＝2,400万円

    - 5：売り建てで値下がりしたのに損失としている（符号の誤り）

- 問8. 【計算型】日経225オプションで、権利行使価格38,000円のコールをプレミアム500円で1枚売り、同じ権利行使価格・限月のプットをプレミアム400円で1枚売った。SQ値が36,800円となった場合の損益と、この戦略の損益分岐点の組合せとして正しいものはどれか（乗数1,000円、手数料等は考慮しない）。
  - 1. 30万円の損失／37,100円と38,900円
  - 2. 30万円の利益／37,100円と38,900円
  - 3. 120万円の損失／37,600円と38,400円
  - 4. 30万円の損失／37,500円と38,500円
  - 5. 210万円の損失／37,100円と38,900円
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**1**
    - 戦略名：同じ行使価格のコール売り＋プット売り＝**ストラドルの売り**（相場が動かないと予想）
    - 受取プレミアム合計＝500＋400＝**900円**
    - SQ値36,800円での各オプション

    - 3：プット支払い1,200円だけを損失とし（受取プレミアムの無視）、分岐点もプレミアム400円のみで計算
    - 4：分岐点をコールのプレミアム500円だけで計算した誤り

- 問9. 【計算型】A社は基準金利＋0.5%の変動金利で10億円を借り入れている。金利上昇に備え、想定元本10億円で「固定金利年1.0%を支払い、基準金利（変動金利）を受け取る」金利スワップを締結した。ある1年間の基準金利が年1.6%であった場合、その1年間のスワップのネット受払額と、借入れとスワップを合わせたA社の実質的な調達金利の組合せとして正しいものはどれか（利払いは年1回とする）。
  - 1. 600万円の支払い／年2.1%
  - 2. 1,600万円の受取り／年1.5%
  - 3. 600万円の受取り／年2.1%
  - 4. 1,000万円の支払い／年1.0%
  - 5. 600万円の受取り／年1.5%
  - 答えと解説 <!-- markmap: fold -->
    - 答え：**5**
    - 金利スワップは**元本を交換せず**、想定元本に基づく**金利の差額**だけを受け払いする
    - スワップの受払い
      - 受取り（変動）：10億円×1.6%＝1,600万円
      - 支払い（固定）：10億円×1.0%＝1,000万円
      - ネット＝1,600万−1,000万＝**600万円の受取り**
    - 借入金利の支払い：10億円×(1.6%＋0.5%)＝2,100万円
    - 実質コスト＝2,100万−600万＝1,500万円 → 1,500万÷10億＝**年1.5%**
    - ポイント：実質金利＝固定1.0%＋上乗せ0.5%＝1.5%で、基準金利がいくらでも一定＝**変動借入を固定化**できている
    - 1：受払いの向きが逆で、スワップ効果を無視した借入金利そのもの
    - 2：変動金利の受取額だけを見て固定払いを差し引き忘れ
    - 3：受払額は正しいが、実質金利にスワップの受取りを反映していない
    - 4：固定払いだけを見て変動受けと上乗せ0.5%を無視
    - 補足：**固定払い・変動受け**は金利上昇で得をするポジション

- 問10. 【計算型】日経225オプションで、権利行使価格38,000円のプットをプレミアム600円で1枚買い、権利行使価格37,000円のプットをプレミアム250円で1枚売った。この戦略の最大利益・最大損失・損益分岐点の組合せとして正しいものはどれか（満期時で考え、乗数1,000円、手数料等は考慮しない）。
  - 1. 最大利益35万円／最大損失65万円／損益分岐点37,350円
  - 2. 最大利益65万円／最大損失35万円／損益分岐点37,350円
  - 3. 最大利益65万円／最大損失35万円／損益分岐点37,650円
  - 4. 最大利益100万円／最大損失35万円／損益分岐点37,650円
  - 5. 最大利益65万円／最大損失85万円／損益分岐点37,650円

    - 5：最大損失をプレミアムの合計（600＋250）とした誤り
