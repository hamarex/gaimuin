# 証券外務員一種 合格マップ

## 使い方（最初に読む）
- 各章は「1. 仕組みの説明 → 2. 試験での出方 → 3. 暗記すべき数字・罰則 → 4. ○×問題と解説 → 5. 五肢選択問題と解説」の順
- ○×問題は答えが**折りたたみ**済み。自分で答えてからノードをクリックして確認
- 【ひっかけ】は本試験で狙われる誤り方。**数字と例外**を優先して暗記
- 試験概要：全100問・440点満点、**7割（308点）以上**で合格
  - ○×問題：70問×2点＝140点
  - 五肢選択：30問×10点＝**300点**（配点の約7割。計算問題が多い）
  - ○×で1文ずつの正誤判定力を作り、五肢選択で「組合せ・計算・絞り込み」を練習する
- 学習順のおすすめ：第2章(金商法) → 第4章(諸規則) → 第6〜8章(株・債券・投信) → 第10章(デリバティブ) → 残り
